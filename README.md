# Medi-Path - Modern Healthcare Management Platform

A comprehensive healthcare management platform built with React, TypeScript, and Tailwind CSS. Streamline patient care with appointment scheduling, medication tracking, secure messaging, and telemedicine capabilities.

## Features

- 🏥 **Patient Management**: Comprehensive patient dashboards and profiles
- 📅 **Appointment Scheduling**: Easy booking and management system
- 💊 **Medication Tracking**: Track prescriptions and medication adherence
- 💬 **Secure Messaging**: HIPAA-compliant communication between patients and providers
- 🎥 **Telemedicine**: Built-in video consultation capabilities
- 🔒 **Privacy & Security**: HIPAA-compliant with advanced security features
- 📱 **Responsive Design**: Works seamlessly on desktop, tablet, and mobile
- 🌙 **Dark Mode**: Toggle between light and dark themes

## What technologies are used for this project?

This project is built with:

- **Frontend**: React 18 with TypeScript
- **Build Tool**: Vite for fast development and builds
- **Styling**: Tailwind CSS with shadcn-ui components
- **Routing**: React Router for navigation
- **State Management**: React Query for server state
- **Icons**: Lucide React for beautiful icons
- **Animations**: Tailwind CSS animations
